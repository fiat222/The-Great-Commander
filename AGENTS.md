# Project Agent Instructions

- Always prefix shell commands with `rtk`.
- Always present a plan and wait for user approval before implementing, modifying files, adding tests, refactoring, or changing project behavior.
- Always present a plan and wait for user approval before running any build command, Unity build, test runner build step, packaging command, or other long-running/generated build workflow.
- If the user only asks whether something is possible, answer conceptually first and do not modify files, implement changes, add tests, or run builds unless explicitly asked.
